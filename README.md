# Automoção de Sistemas e processos com Python

## Descrição

Este projeto foi desenvolvido em Python
com o objetivo de automatizar tarefas.

## Tecnologias utilizadas

- Python 3
- Visual Studio Code
- Git e GitHub

## Requisitos

- Python instalado
- Pip disponível

## Instalação

1. Clone o repositório:

```bash
git clone https://github.com/fredhansenads/projeto1automocaoPython.git
```

2. Crie o ambiente virtual:

```bash
python -m venv venv
```

3. Ative o ambiente virtual no Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

4. Instale as dependências:

```bash
pip install -r requirements.txt
```

## Execução

Execute o programa:

```bash
python main.py
```
